# 요구사항별 구현 현황과 iOS 제약 (정직한 대조표)

Jarvis는 요청서의 25개 요구사항을 모두 코드로 다룹니다. 다만 일부는 **iOS(아이패드OS) 자체가 앱에 허용하지 않는 동작**이어서, 같은 목적을 달성하는 가장 가까운 공식 방법으로 대체했습니다. 아래 표의 표시는 다음과 같습니다.

- ✅ 요청 그대로 구현
- 🟡 iOS 제약 때문에 대체 방식으로 구현 (아래 "대체 방식" 참조)
- ⚠️ 기기에서 직접 확인이 필요한 부분 (CI에서 컴파일·시뮬레이터 실행까지만 검증)

## Swift Playgrounds로 실행할 때의 추가 제약

- **아이폰에서는 Swift Playgrounds가 없습니다.** 같은 패키지를 Playgrounds의 "App Store Connect에 업로드" → TestFlight(유료 Apple 개발자 계정 필요) 또는 Mac의 Xcode로 설치하면 아이폰에서도 그대로 동작합니다.
- Playgrounds 안에서 실행하는 앱은 독립 설치 앱이 아니므로 Siri 앱 단축어·Spotlight 같은 App Intents 연동은 **설치형에서만** 활성화됩니다. 대신 이름이 "Wake up Jarvis"인 일반 단축어(`jarvis://wake`)가 Siri·AssistiveTouch·제어 센터에서 같은 역할을 합니다.
- Playgrounds 앱 설정 화면에서 이름·아이콘·권한을 바꾸면 Playgrounds가 `Package.swift`를 다시 쓰면서 `additionalInfoPlistContentFilePath: "Info-Extra.plist"` 줄이 사라질 수 있습니다. 이 줄이 빠지면 백그라운드 오디오·`jarvis://` 링크·파일 앱 노출이 꺼지므로 다시 추가하십시오.

## 기기에서만 확인할 수 있는 것

CI는 매 커밋마다 ① 핵심 로직 67개 단위 테스트(리눅스·macOS), ② iOS 시뮬레이터용 전체 앱 컴파일, ③ iPad 시뮬레이터에서 앱 실행과 실제 명령 4개의 끝-끝 동작(3D 공간 열기 → 큐브 생성 → 복제 → 한국어 명령으로 언어 전환)을 로그·스크린샷으로 검증합니다. 다음은 실제 기기에서만 확인할 수 있습니다: 마이크·음성 인식 정확도, 에코 제거와 끼어들기, Apple Intelligence 응답, Kokoro 음성(뉴럴 엔진), 카메라 손 인식, PiP 백그라운드 동작, GPU(Metal) 심층 사고 모델 속도. 첫 실행 체크리스트는 [SETUP.ko.md](SETUP.ko.md) 7장에 있습니다.
